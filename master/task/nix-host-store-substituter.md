# Optional host Nix store as read-only substituter

Let the `cast-nix-daemon` container substitute store paths from the host's
`/nix` instead of rebuilding or re-downloading them, without sharing a store,
a daemon, or any configuration with the host.

Opt-in, off by default, Linux hosts only. Store *contents* flow host to
container only; configuration remains fully separated and cast keeps
ownership of its daemon and its nix.conf.

## Approach

Bind-mount the host `/nix` read-only at `/host-nix/nix` in the **daemon
container only** — dev containers must not receive this mount. A local store
rooted at `R` places its store dir at `R/nix/store` and its db at
`R/nix/var/nix/db`, so this layout exposes the host store as a valid chroot
store. Then add to the `NIX_CONFIG` generated by `nix_daemon/config.rs`:

```
extra-substituters = local?root=/host-nix&read-only=true&trusted=true&priority=10
extra-trusted-substituters = local?root=/host-nix&read-only=true&trusted=true&priority=10
```

All three parameters are load-bearing:

- `read-only=true`: nix opens the store db read-write even for queries and
  fails on a read-only mount without this.
- `trusted=true`: locally built host paths are unsigned, so every
  compile-time saving depends on accepting unsigned substitutes from here.
- `priority=10`: keeps real binary caches ahead of the host store (default
  priority 0), so this acts as the fallback that avoids compilation.

Substitution copies paths, so disk duplication is unchanged and out of scope
for this task.

## Scope notes

- Config flag on `config::schema` following the existing `bool` opt-in
  pattern (cf. `add_host_docker_internal`).
- Refuse to enable on non-Linux hosts, and on VM-backed engines, with a clear
  message rather than silent no-op. Rationale in report section 5.
- Degrade gracefully: if `/nix` is absent, unreadable, or its db schema is
  newer than the daemon image's nix can read, warn and run without the
  substituter. Never fail a session because of it.
- Do not mount the host store into dev containers.
- Do not add the reverse direction (host substituting from the cast store).
  Report section 3D-reverse: it is a host code execution path.
